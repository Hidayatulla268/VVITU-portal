Enterprise Features

Built for Scalable Academic Excellence

Every feature engineered for high data integrity, automation, and real-time administrative intelligence.

Student Counselling Dossier & PDF

Compiles demographic data, family profiles, pending fee status, 8-semester exam SGPA/CGPA, subject attendance records, and achievements into an official multi-page ReportLab PDF document with running canvas headers and signatures.

Class Diary & Syllabus Coverage

Faculty log period-by-period class topics, unit numbers (Units 1 to 5), and teaching methodology. HODs and Admins track real-time departmental syllabus progress percentages with visual progress meters.

Attendance Prefill & Multi-Period Sync

Automatically pre-fills student class lists with default status 'Present' to save faculty marking time. Multi-period sync propagates attendance records across consecutive timetable period slots instantly.

R23 Regulation SGPA / CGPA Engine

Implements JNTUK/R23 academic regulations — Mid 1, Mid 2, Final, and Supplementary exam grading (Letter grades S=10 to F=0), active backlog tracking, and dynamic cumulative CGPA calculation.

Parent SMS & Low-Attendance Alerts

Automated SMS notification pipeline that alerts parents when student attendance falls below the mandatory 75% threshold, ensuring proactive intervention and legal compliance.

Role-Based Access Control (RBAC)

Five strictly scoped roles (Admin, HOD, Faculty, Student, DEO) guarded by custom Django middleware to enforce data privacy, departmental scoping, and action authorization.

Quick Start

Run Locally in 4 Steps

Clone the repository and spin up the complete environment in under 3 minutes.

01
Clone & Setup Venv

git clone https://github.com/Hidayatulla268/VVITU-portal.git

02
Install Dependencies

pip install -r requirements.txt

03
Migrate & Seed Data

python manage.py migrate && python manage.py seed_data

04
Launch Dev Server

python manage.py runserver
